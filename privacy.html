Privacy Policy

Last updated:

Your screenshots never leave your device

This tool reads image files you select or drag in using your browser's File API, and processes them using the Canvas API — entirely inside your browser. No screenshot, filename, or image data is transmitted to any server, and none is stored once you close or refresh the page.

What we don't collect

We don't collect accounts, passwords, or personal information through this tool, and there is no database behind it.

Basic web analytics

If this site is deployed with a standard web analytics or hosting provider, that provider may log standard technical data (such as page views or approximate location from IP address) the way most websites do. Replace this section with the specifics of whatever analytics you add before launch.

Third-party fonts

This page loads fonts from Google Fonts, which may log requests according to Google's own privacy policy.
